# Hahne Digital – Website

Dieses Projekt ist für GitHub Codespaces vorbereitet.

## In Codespaces starten

1. Repository auf GitHub hochladen.
2. Auf **Code → Codespaces → Create codespace on main** klicken.
3. Im Terminal ausführen:

```bash
npm run dev
```

4. Port **3000** wird automatisch weitergeleitet und als Vorschau geöffnet.

## Dateien bearbeiten

- `index.html` – Inhalte und Seitenstruktur
- `css/style.css` – Farben, Typografie, Abstände und Responsive Design
- `js/script.js` – Demos, Projekt-Check und Kontaktformular

## Wichtig vor Veröffentlichung

Im Kontaktformular in `js/script.js` muss `IHRE-EMAIL@DOMAIN.DE` durch die echte Geschäfts-E-Mail-Adresse ersetzt werden. Außerdem müssen Impressum und Datenschutz ergänzt bzw. verlinkt werden.
